# 1.1 发布验收

## 交付范围

1.1.0 交付 Windows 10 22H2 x64 兼容和翻译框布局设置。Windows 10、Windows 11 共用应用代码、普通版和开发版安装包。最低系统版本为 build 19045；Python 3.13 与 Qt 6.12 保持不变。

翻译框支持宽高倍数、内外边距、横纵对齐、字号倍数、自动扩框上限和相邻内容避让。自动扩框可选固定大小、仅增高或同时扩宽增高。默认目标字号为原文估算值的 1.1 倍；字号测量使用实际设备像素，原始识别框保持独立，反复调参和缩放窗口均重新计算。

本版补齐独立推理进程所需的应用内 MSVC 运行库，分发的解释器通过程序清单启用 UTF-8 代码页。SentencePiece 通过 Python 读取模型字节。主题标签在深浅色信号到达时立即更新文字颜色；词典语言对根据实际文件列表刷新，同一目录时间戳的增删也立即生效。

## 回归与复现

最终完整回归为 4591 项通过、16 项条件跳过，耗时 692.35 秒。跳过项为三项原生字体 bbox 检查、四项原生深浅色检查、八项按需截图检查和一项 CUDA 子进程依赖检查。bbox 与深浅色检查已在原生 Windows 中另行通过；CUDA 子进程返回依赖错误 65，其硬件验证范围继续保留。

代码规范通过，532 份受检查文件格式一致，严格类型检查为 0 错误、0 警告，八项依赖约束全部通过。词典模块的 62 项检查通过，包含目录时间戳保持相同的新增和删除操作。

完整回归使用 `QT_QPA_PLATFORM=offscreen`。原生排版与主题使用 `QT_QPA_PLATFORM=windows`，窗口通过测试夹具设置为不在桌面显示。设置窗口的夹具作用域独立运行：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
$env:QT_QPA_PLATFORM = 'offscreen'
.venv/Scripts/python.exe -m pytest -q

$env:QT_QPA_PLATFORM = 'windows'
.venv/Scripts/python.exe -m pytest tests/ui/test_theme_icons.py tests/ui/test_windows10_theme.py tests/ui/test_theme_style.py tests/fidelity/test_box_layout.py tests/ui/overlay/test_box_layout.py
.venv/Scripts/python.exe -m pytest tests/ui/settings/test_box_layout.py tests/ui/settings/test_appearance.py
```
